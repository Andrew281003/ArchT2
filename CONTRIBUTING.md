# Contributing to ArchT2

ArchT2 is experimental and in Phase 0. Contributions should help make the project's research and future implementation reproducible without overstating hardware support.

## Before contributing

- Check existing issues and documentation to avoid duplicating work.
- For hardware claims, include the exact model identifier, software versions, method, outcome, and relevant logs with private identifiers removed.
- Do not submit credentials, personal diagnostic data, machine identifiers, proprietary firmware, or material whose redistribution rights are unclear.
- Keep third-party source, license text, and attribution intact. Project-authored code is GPL-3.0.

## Changes

Use focused pull requests with a clear summary, rationale, and verification steps. Documentation changes should distinguish measured results from assumptions. Do not claim compatibility based on an untested configuration. Avoid adding speculative drivers or configuration files without evidence and a clear project need.

For code changes, describe how you checked the change and include or update a small relevant test when practical. Do not include private device logs without sanitizing them.

## Issues

Use the issue templates for public bug reports and feature proposals. Do not report security vulnerabilities in public issues; follow [SECURITY.md](SECURITY.md).
